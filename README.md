# AI Forensic Sketch Assistant

An AI-powered forensic sketch generation application that helps witnesses create and refine suspect sketches using natural voice commands.

## Vision

Traditional forensic sketch creation requires a police sketch artist and can take considerable time. This project explores an AI-assisted workflow where a witness can describe a suspect using voice, and the system updates the sketch in real time.

## Planned Features

- 🎤 Voice input
- 🗣️ Speech-to-text transcription
- 🧠 AI prompt generation
- 🎨 AI image generation
- 🔄 Real-time sketch refinement
- 💾 Save investigation sessions
- 📤 Export sketches
